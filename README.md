## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ৫০টি ভেরিফাইড প্রবাস সমস্যার সমাধান (50 Verified Problem Workflows)
- ১৭টি ক্যাটাগরিতে বিভক্ত (ইকামা ও রেসিডেন্সি, কাফালা ও স্পনসরশিপ, কিওয়া ও লেবার কন্ট্রাক্ট, শ্রম আদালত ও পাওনা, পুলিশ ও তারহিল, ড্রাইভিং ও নাজম, হুরূব, ইত্যাদি)।
- প্রতিটি সেবায় রয়েছে:
  - সরকারি ধাপে ধাপে নির্দেশিকা (Step-by-Step Execution Guide)
  - প্রয়োজনীয় নথিপত্রের চেকলিস্ট (Official Documents Checklist)
  - সম্ভাব্য ফাঁদ ও দালালের প্রতারণা সতর্কবার্তা (Official Warning & Anti-Scam Advisory)
  - অডিও ভয়েস অ্যাসিস্ট্যান্ট (Web Speech TTS)
  - ওয়ান-ক্লিক হোয়াটসঅ্যাপ ডিরেক্ট লিড সাবমিশন

### ২. সৌদি শ্রম আইন ধারা ৮৪ ও ৮৫ গ্র্যাচুইটি ক্যালকুলেটর (Article 84 & 85 Calculator)
- চুক্তি সমাপ্তি (Termination) বনাম পদত্যাগ (Resignation)-এর নিখুঁত হিসাব:
  - ২ বছরের কম: 0%
  - ২ থেকে ৫ বছর: ১/৩ অংশ (Article 85)
  - ৫ থেকে ১০ বছর: ২/৩ অংশ (Article 85)
  - ১০ বছরের ঊর্ধ্বে: ১০০% পূর্ণ গ্র্যাচুইটি
- রিয়াল (SAR) থেকে তাৎক্ষণিক টাকায় (BDT) কনভার্সন এবং বাংলাদেশ সরকারের ২.৫% প্রণোদনাসহ হিসাব।

### ৩. আরবি দরখাস্ত জেনারেটর (Arabic Legal Letter Generator)
- সৌদি মন্ত্রণালয়, লেবার অফিস, পাসপোর্ট অধিদপ্তর (জাওয়াজাত), ও ট্রাফিক পুলিশ (মুরুুর)-এর জন্য ফর্মাল আরবি চিঠি তৈরির সুবিধা।
- প্রিভিউ, কপি ও সরাসরি প্রিন্ট-রেডি (A4 Print Preview) ফরম্যাট।

### ৪. জরুরি এসওএস ও জিপিএস শেয়ারিং (Urgent SOS & GPS Dialer)
- সৌদি আরবের সকল ইমার্জেন্সি হটলাইন (পুলিশ ৯৯৯, অ্যাম্বুলেন্স ৯৯৭, সিভিল ডিফেন্স ৯৯৮, নাজম ৯২০০১৪৪৪৪, রিয়াদ দূতাবাস ও জেদ্দা কনস্যুলেট)।
- রিয়েল-টাইম জিপিএস কোঅর্ডিনেট লোকেশন কপি ও হোয়াটসঅ্যাপে ইমার্জেন্সি সেন্ড সুবিধা।
- জরুরি মুহূর্তে বলার মতো আরবি বাক্য উচ্চারণসহ (Phonetic Arabic phrases)।

### ৫. লাইভ রিয়াল-টাকা রেমিট্যান্স ক্যালকুলেটর (Live SAR-BDT Remittance Widget)
- শীর্ষ এক্সচেঞ্জ ওয়ালেটগুলোর রেট তুলনা (STC Pay, Urpay, Tahweel Al Rajhi, Enjaz, Alinma Pay, Western Union)।
- বাংলাদেশ সরকারের অফিসিয়াল ২.৫% ক্যাশব্যাক প্রণোদনার স্পষ্ট ব্রেকডাউন।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend & Routing:** Next.js 14 (App Router)
- **Type Safety:** TypeScript 5.6
- **Styling & Design System:** Tailwind CSS (Dark/Emerald Palette inspired by Saudi Flag & Bangladeshi Green/Red)
- **Icons & Visuals:** Lucide React
- **Database (Ready):** PostgreSQL / Supabase with GIN Full-Text Indexing
- **Deployment Platform:** Vercel (Edge Network)
- **CI / Automation:** Python 3 (Remittance Scraper, Live Route Auditor, Meta Graph API Agent)

## 💻 লোকাল ডেভেলপমেন্ট (Local Setup)

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/sultantipu199/probashi-hub.git
cd probashi-hub

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. এনভায়রনমেন্ট ফাইল কনফিগার করুন (.env.local)
cp .env.example .env.local

# ৪. লোকাল ডেভ সার্ভার রান করুন
npm run dev
# ব্রাউজারে ওপেন করুন: http://localhost:3000

# ৫. টাইপ-চেক এবং প্রোডাকশন বিল্ড যাচাই
npx tsc --noEmit
npm run build
```
